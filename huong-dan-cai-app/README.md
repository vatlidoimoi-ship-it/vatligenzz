# Hướng dẫn cài app PHYEDU

Đây là website tĩnh dùng để hướng dẫn học sinh và giáo viên cài PHYEDU dạng PWA trên iPhone/iPad, Android và máy tính.

## Cách mở

Mở file `index.html` trực tiếp trong trình duyệt.

## Cấu trúc

- `index.html`: nội dung và bố cục trang hướng dẫn.
- `css/styles.css`: giao diện responsive.
- `js/main.js`: tab thiết bị, đồng bộ link web và sao chép link.
- `assets/install-preview.png`: ảnh minh họa đầu trang.

## Khi đưa lên web chính

Có thể copy folder này lên hosting riêng, hoặc gắn vào Flask thành route `/install` nếu muốn nằm chung trong LMS.
